
# Sentiment Analysis Classifier

This project is a part of Cornell's Break Through Tech Program. 

## Project Description 📋

This project tests out different ways to process book review text (TF-IDF and WORD2VEC) and tests two different models (logistic regression and decision trees) using those different approaches. After tuning the different parameters and testing the different models, the logisitic regression produced the highest accuracy out of all combinations. After further optimization of the logistic regression model, it was tested on an external movie review dataset to test the model's ability to generalize outside of book review data.
